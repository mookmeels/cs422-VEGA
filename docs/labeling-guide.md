# Labeling guide

Used when hand-checking the labeler's suggestions, so that every rater judges the same way.

## The task

For each image, the review sheet shows the labeler's top 5 aesthetics with scores. Mark each one **fits** or **doesn't fit**. Judge from the photo and the aesthetic's wiki description, not from the score.

## Second rater

The second rater marks the same images without seeing the first rater's marks, so the agreement score (Cohen's kappa) is honest. Disagreements are discussed afterwards and recorded in `discussion-log.md`.
