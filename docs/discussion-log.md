# Discussion log

Required by the course: record every substantive discussion during planning and after reviewing results. A list of meeting dates alone is not enough. At least one entry must show how discussion changed an experiment, an interpretation or a recommendation. Rejected proposals belong here too, with the reason.

Copy this block for each discussion, newest at the bottom.

```
## YYYY-MM-DD: <topic>
- Participants:
- Question or disagreement:
- Evidence considered:
- Decision:
- Resulting action:
```
