# cnn

Convolutional neural network model: a ResNet-18 trained from scratch on the wiki gallery pictures, with an optional second output trained on Street Fashion Style photos ("CNN (ResNet-18, 224 px) + street photos" in the team table). Owner: Giancarlo Guevarra.

Everything about it (how to run it, every setting and how it was chosen, results, timings, the final run) is in [README.txt](README.txt). It uses the team's loader and scorer in `src/common/`.
